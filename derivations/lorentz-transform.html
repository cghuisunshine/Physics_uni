Derive the Lorentz transform, length contraction and velocity addition

Homogeneity makes inertial coordinate transformations linear. Since x′ = 0 follows x = vt, write x′ = A(x − vt). Requiring both light rays x = ±ct to satisfy x′ = ±ct′ fixes t′ = A(t − vx/c²).

What the symbols mean

v: frame S′ speed relative to S; γ = 1/√(1 − v²/c²); primed and unprimed coordinates refer to the same event.

When this applies

Special-relativistic inertial frames, aligned axes, origins coincident at t = 0, homogeneity and isotropy.

Developing the argument

Use linearity and the moving origin

Homogeneity makes inertial coordinate transformations linear. Since x′ = 0 follows x = vt, write x′ = A(x − vt). Requiring both light rays x = ±ct to satisfy x′ = ±ct′ fixes t′ = A(t − vx/c²).

Derived resultx′=A(x−vt)t′=A(t−vxc2)\begin{gathered}x'=A(x-vt)\\[0.35em]t'=A\left(t-\frac{vx}{c^2}\right)\end{gathered}x′=A(x−vt)t′=A(t−c2vx​)​Read the reasoning above ↑

Impose inverse-frame reciprocity

The inverse has speed −v and the same scale A by isotropy. Substituting transformations gives A²(1 − v²/c²) = 1. Choose positive A continuously connected to v = 0.

Derived resultA=γy′=yz′=z\begin{gathered}A=\gamma\\[0.35em]y'=y\\[0.35em]z'=z\end{gathered}A=γy′=yz′=z​Read the reasoning above ↑

Measure moving endpoints simultaneously

An object at rest in S′ has proper length Δx′ = L₀. The S measurement requires Δt = 0; hence Δx′ = γΔx.

Derived resultL=Δx=L0γL=\Delta x=\frac{L_0}\gammaL=Δx=γL0​​Read the reasoning above ↑

Divide coordinate differentials

Use the inverse transform dx = γ(dx′ + vdt′) and dt = γ(dt′ + vdx′/c²). Their ratio gives longitudinal velocity addition.

Derived resultu=dxdt=u′+v1+u′v/c2u=\frac{\dd x}{\dd t}=\frac{u'+v}{1+u'v/c^2}u=dtdx​=1+u′v/c2u′+v​Read the reasoning above ↑
Check the result

A worked example

Combining u′ = 0.8c and v = 0.8c gives u ≈ 0.976c, below c.

Derivation behind this calculation ↗

A point to keep straight

Length measurements require simultaneous endpoint events in the measuring frame. Time and position cannot be transformed independently.
